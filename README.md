# Poultry Farm Management App

This is a simple full-stack web application for managing a poultry farm. It includes a backend built with Node.js and Express, and a frontend built with React.

## How to Run the Application

You will need to have [Node.js](https://nodejs.org/) and `npm` installed on your computer.

You will need to open **two separate terminal windows** to run both the backend and the frontend servers.

### 1. Run the Backend Server

In your first terminal window, follow these steps:

1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```

2.  Install the necessary dependencies:
    ```bash
    npm install
    ```

3.  Start the backend server:
    ```bash
    npm start
    ```

The backend server will be running on `http://localhost:3001`. You should see a message in the terminal confirming that the server is running and connected to the database. Leave this terminal window open.

### 2. Run the Frontend Application

In your second terminal window, follow these steps:

1.  Navigate to the `frontend` directory:
    ```bash
    cd frontend
    ```

2.  Install the necessary dependencies:
    ```bash
    npm install
    ```

3.  Start the frontend application:
    ```bash
    npm start
    ```

This command will automatically open a new tab in your default web browser with the application running at `http://localhost:3000`.

You can now view and interact with the application.
